# STM32F072RB CMake Project Boilerplate

This is an opinionated boilerplate for STM32F072RB development using alternative IDEs like VS Code (via the STM32 VS Code Extension).  
It provides a minimal Git repository containing only the essential files — STM32 HAL libraries can be regenerated at any time using STM32CubeMX.

---

### 📁 Project Structure

User code should be written in the `App/Src` folder.  
The functions `App_Init()` and `App_Loop()` are defined in [`App/Src/app_main.c`](App/Src/app_main.c), and are called from the original [`main.c`](Core/Src/main.c#L92-L104).  

This design encourages avoiding direct modifications to autogenerated files. If customization is necessary, add function calls in `Core/Src`, but keep the implementation in `App/Src`.

Note: The [`.gitignore`](.gitignore) is configured to exclude most autogenerated files. If you need to track changes in specific `Core/` files, you may need to update it accordingly.

---

### 💡 Using Other Boards

To use this boilerplate with a different STM32 MCU or board:

1. Delete the existing `.ioc` file (`STM32F072RB_Starter.ioc`)
2. Create a new project in STM32CubeMX for your target MCU
3. Copy the newly generated `.ioc` file into the project root

### 🧪 Getting Started

#### 1. Clone the repository
```bash
git clone https://github.com/aircey/STM32F072RB_Starter
cd STM32F072RB_Starter
```

#### 2. Run the setup script

```bash
python3 ./start.py
```

The script will prompt you to:

* Enter a new project name
* Optionally delete the existing `.git` directory
* Optionally rename the current project folder

#### 3. Generate STM32 code

* Open `your_project_name.ioc` in STM32CubeMX
* (Optional) Configure pinout and clocks
* In **Project Manager > Code Generator**, ensure **"Copy only the necessary library files"** is selected

#### 4. Import into your IDE (VS Code)

* Click **"Import CMake project"**
* Select the project directory
  (Extra configuration files will be generated automatically)

#### 5. Code, Build, Debug, Repeat...
